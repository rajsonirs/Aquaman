# AquaGuard — Smart Water Leak Detection

End-to-end AI portfolio project that scores water meter readings for sustained anomalies, shows alerts in a dashboard, and exposes a REST API.

> **Data honesty:** The built-in sample readings are synthetic and generated by this project. They are not field measurements. A demo on simulated readings does not prove real-world accuracy.

## Features

- Isolation Forest detector with time-series features and a persistence filter.
- Streamlit dashboard with flow chart, alert table, optional labeled-data metrics, and CSV export.
- FastAPI endpoints for JSON and CSV analysis.
- Reproducible synthetic sample-data generator and Docker setup.

## Quick start (Python 3.10+)

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run dashboard/app.py
```

The dashboard starts with 14 days of simulated data. Upload your own CSV to analyze it.

## CSV format

Required columns: `timestamp` (date/time) and `flow_lpm` (non-negative liters per minute). Optional: `pressure_kpa`, `leak_label` (1 leak, 0 normal), and `sensor_id`. Use at least 20 rows. If labels are present, the model fits on presumed-normal rows. Metrics on the same rows are diagnostic, not unbiased test results.

Generate a CSV sample:

```bash
python scripts/generate_data.py
```

## API

```bash
uvicorn aquaguard.api:app --app-dir src --reload
```

Open http://127.0.0.1:8000/docs. Endpoints: `GET /health`, `GET /demo`, `POST /analyze` (JSON array), and `POST /analyze-csv` (CSV file).

## Docker

```bash
docker compose up --build
```

Open http://localhost:8501.

## Evaluation guidance

Do not report training-set metrics as test performance. Split by complete experiment, meter, or date range before tuning. Report precision, recall, F1, false alarms per day, and detection delay. Compare against a simple overnight-flow threshold; accuracy alone is misleading when leaks are rare.

A public starting point is [LeakTestbed](https://waterfutures.github.io/WaterBenchmarkHub/benchmarks/LeakTestbed.html), a laboratory benchmark with induced leaks and no-leak readings. Check its terms and documentation before using or redistributing the data.

## Architecture

```text
CSV / sample generator → validation → features → Isolation Forest
                                              ↓
                              persistence filter → alerts and metrics
                                  ↙                         ↘
                          Streamlit dashboard           FastAPI
```

## Limitations and next steps

This is a decision-support prototype, not a safety-critical controller. Sensor cadence, meter calibration, occupancy, seasonality, and sensor faults affect results. Validate on representative labeled data before operational use. A production design also needs site-specific training, sensor-health and drift monitoring, API authentication, data-retention controls, and human review.
